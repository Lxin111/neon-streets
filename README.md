## 🎮 项目简介

**NEON STREETS（霓虹街区）** 是一款使用 Three.js 与 Vite 开发的第一人称 3D 近战动作游戏。游戏以霓虹都市街道为舞台，玩家需要清理敌人、挑战 Boss、收集资源、解锁武器与强化能力，并沿道路出口不断推进。

- **在线试玩：** https://lxin111.github.io/neon-streets/
- **GitHub 仓库：** https://github.com/Lxin111/neon-streets
- **技术栈：** Three.js 0.180、Vite 7、JavaScript
- **游玩方式：** 现代桌面浏览器与移动浏览器，无需下载独立安装包
- **部署方式：** GitHub Pages + GitHub Actions

## ✨ 游戏特色

### 战斗与武器
- 第一人称视角战斗，支持移动、冲刺、近战攻击与武器技能。
- 多种可解锁、可切换的武器，包括太刀、太阳神剑、魔刀千刃与 AK47。
- 太刀剑气等远程攻击效果，让近战战斗拥有更多变化。
- 敌人、精英敌人与 Boss 拥有不同的战斗定位。

### 敌人与难度
- 包含普通敌人、精英敌人与多种 Boss。
- 已进行难度平衡：Boss 生命值下调至原来的约四分之一，精英敌人生命值下调至原来的约二分之一；绿巨人 Boss 也已单独调整。
- 持续优化敌人战斗表现与玩家受击、格挡等反馈。

### 霓虹都市与街区推进
- 程序化生成城市楼宇、窗户、霓虹招牌、街灯与道路装饰。
- 使用环境光、阴影、ACES 色调映射与 Bloom 泛光营造夜间城市氛围。
- 每六个街区组成一个循环；清理当前街区后，需要走到道路出口才能进入下一区域。

### 成长与奖励
- 击败敌人获取经验与金币。
- 通过商店购买强化，收集核心并手动装备。
- 成就系统根据累计击杀数量解锁，并提供金币奖励。
- 宝箱与奖励拾取物为探索和战斗提供额外收益。

### 桌面与手机
- 桌面端支持键盘、鼠标操作。
- 移动端提供虚拟摇杆、触屏视角控制与屏幕战斗按钮。
- 启动界面显示精确到两位小数的加载进度及当前初始化阶段。

## 🕹️ 操作说明

### 桌面端

| 按键 / 操作 | 功能 |
| --- | --- |
| WASD / 方向键 | 移动 |
| Shift | 冲刺 |
| 鼠标移动 | 转动视角 |
| 点击游戏画面 | 请求鼠标指针锁定 |
| 鼠标左键 | 普通攻击 |
| R | 武器奥义 |
| E | 开启附近宝箱 |
| C | 打开 / 关闭角色属性与核心面板 |
| 数字键 1–4 | 切换已解锁武器 |
| Esc | 释放鼠标指针锁定 |

### 移动端

使用屏幕左侧虚拟摇杆移动，滑动屏幕调整视角，并使用右侧按钮进行攻击、闪避、格挡、居合和武器切换。

## 🧰 本地运行

需要安装 **Node.js 20.19+ 或 22.12+**。

```bash
git clone https://github.com/Lxin111/neon-streets.git
cd neon-streets
npm install
npm run dev
```

使用浏览器打开 Vite 显示的本地开发地址。

### 构建与预览

```bash
npm run build
npm run preview
```

## 🚀 自动部署

项目使用 GitHub Actions 自动构建并发布到 GitHub Pages。向 `main` 分支推送提交后，会触发构建与部署流程。

**在线版本：** https://lxin111.github.io/neon-streets/

## 🧪 测试与开发状态

项目仍在积极开发中。仓库已加入自动化浏览器冒烟测试，覆盖桌面端与移动端基本启动流程；近期也持续修复战斗逻辑、加载与部署相关问题，并进行性能优化。

当前游戏中的城市与角色主要由程序化几何体和材质构成，**并非直接使用《赛博朋克 2077》的原版资产，也不代表已经达到真人扫描或光线追踪级别的画面效果**。实际体验可能因设备性能和浏览器而异。

### 后续开发方向
- 提升角色、敌人与 Boss 的模型质量、动作动画及受击反馈。
- 加强披风、武器等物体的动态表现。
- 丰富街区事件、敌人种类、武器技能与 Boss 战。
- 改进地面材质、反射、粒子效果及城市环境细节。
- 增加画质档位、设备性能自适应与存档功能。
